# Stockroom

ระบบสต็อกสำหรับหลายคลัง ใช้ Next.js, Go และ PostgreSQL

## เริ่มใช้งานในเครื่อง

ต้องมี Go ตามเวอร์ชันใน `backend/go.mod`, Node.js 22+, npm และ PostgreSQL ที่กำลังทำงาน

สร้างฐานข้อมูลเปล่าและให้สิทธิ์บัญชีที่ Go จะใช้สร้างตาราง จากนั้นเปิดเทอร์มินัลแรกที่รากโปรเจกต์

```sh
cd backend
export DATABASE_URL='postgres://inventory_user:YOUR_DB_PASSWORD@127.0.0.1:5432/inventory'
export ADMIN_USERNAME='admin'
printf 'รหัสผ่านบัญชีแรก (อย่างน้อย 12 ไบต์): '
read -rs ADMIN_PASSWORD
printf '\n'
export ADMIN_PASSWORD
go run .
```

Backend ใช้ migration เพื่อสร้างตาราง และสร้างบัญชีแรกเมื่อฐานข้อมูลยังไม่มีผู้ใช้ หากต้องเปลี่ยน URL ที่ผู้ใช้เปิด ให้ตั้ง `APP_ORIGIN` เป็น origin ที่ตรงกัน ค่าเริ่มต้นคือ `http://localhost:3000` และ API ฟังที่ `127.0.0.1:8080`

เปิดเทอร์มินัลที่สองที่รากโปรเจกต์

```sh
cd frontend
npm ci
npm run dev
```

เปิด `http://localhost:3000` และเข้าสู่ระบบด้วยบัญชีที่สร้างไว้ เพิ่มสินค้าและคลัง จากนั้นเลือก **บันทึกรายการ** บนหน้ายอดคงเหลือ หากย้าย Go ไปยังที่อยู่อื่น ให้ตั้ง `API_URL` ของ Next.js ก่อนเริ่ม dev server หรือก่อน build

## ขอบเขตที่ใช้งานได้

- เข้าสู่ระบบ ออกจากระบบ และจัดการสินค้าและคลัง
- รับเข้า เบิกออก โอนคลัง และปรับยอด พร้อมค้นหายอดและประวัติ
- อัปเดตยอดและประวัติใน transaction เดียว ตรวจยอดพร้อมล็อกแถว และป้องกันการบันทึกซ้ำเมื่อส่งคีย์เดิม
- เมื่อปรับยอด ให้กรอกยอดที่เห็นก่อนเริ่มตรวจนับและยอดที่ตรวจนับได้ ระบบตรวจเทียบยอดเดิมก่อนบันทึก

บัญชีรุ่นนี้เข้าถึงทุกคลังได้ งานที่ยังอยู่ในแผน ได้แก่ บทบาทและสิทธิ์แยกตามคลัง การปิดใช้งานข้อมูลหลัก รายการกลับยอด ตัวกรองวันที่ รายละเอียดรายการแบบ API แยก และ OpenAPI contract

## ตรวจสอบโค้ด

รัน `go test ./...` ใน backend เพื่อตรวจการคอมไพล์ และ `npm run build` ใน frontend เพื่อตรวจ TypeScript และ build สำหรับเริ่ม production server
